# Teken & Leef

Tekenapp voor kinderen (±6–8 jaar), werkt als app op een Android-tablet (PWA, geen Play Store nodig).

- Stap-voor-stap overtekenen met uitleg (voorgelezen): vis, olifant, vogel, eenhoorn, fee
- Foto van een papieren tekening → wordt uitgeknipt en "komt tot leven" in een zee, lucht, weide of sprookjeswereld
- Tik op het dier voor een draai + geluid, filmpje opnemen, tekeningen bewaren

## Installeren op de tablet
1. GitHub → Settings → Pages → Source: *Deploy from a branch* → branch `claude/kids-drawing-tutorial-app-v3tv3m`, map `/docs` → Save (repo moet publiek zijn, of GitHub Pro/Team)
2. Open `https://hervedebraekeleer-cmd.github.io/General/` in Chrome op de tablet
3. Menu ⋮ → *App installeren* / *Toevoegen aan startscherm*

Daarna werkt de app ook zonder internet. Code staat in `docs/`.
